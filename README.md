# 🌊 Projeto de Geração de Ondas Senoidais e 2D em Python

Este repositório contém um projeto de simulação e visualização de **ondas senoidais** e **ondas bidimensionais (2D)** usando **Python**. O foco é demonstrar o comportamento de ondas em diferentes configurações, com representações gráficas interativas ou animadas.

## 🎯 Objetivo

O objetivo do projeto é criar ferramentas visuais e computacionais que ajudem a entender fenômenos ondulatórios — como propagação, interferência e variações de frequência — utilizando conceitos de física e matemática aplicados em Python.

## 🛠 Tecnologias utilizadas

- Python 3.x
- `numpy` — para cálculos numéricos e funções matemáticas
- `matplotlib` — para visualização gráfica e animações
- `scipy` (opcional) — para manipulações mais avançadas

## 🧪 Funcionalidades

- Geração de **ondas senoidais simples** (1D)
- Visualização de **ondas 2D** (superfície)
- Animações de propagação de ondas ao longo do tempo
- Parâmetros ajustáveis: frequência, amplitude, fase, velocidade
- Representação interativa com sliders (em versões com `matplotlib.widgets`)
